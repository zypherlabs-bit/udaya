# Udaya Mining Campaigns

## Testnet Mining Tournament
**Duration**: Ongoing
**Rewards**: Top miners earn mainnet UDYA allocation
**Metrics**: Blocks found, uptime, shares submitted
**Leaderboard**: Live at /mining/leaderboard

## Node Operator Rewards Program
**Reward**: 10 tUDYA per day for running a full node
**Requirements**:
- Node uptime > 99%
- At least 8 outbound peer connections
- Validating and relaying blocks
- Running latest software version

## Early Miner Rewards
**Period**: First 210,000 blocks
**Bonus**: +5% block reward for miners in under-represented regions
**Regions**: Africa, South America, Southeast Asia
**Verification**: Geographic IP verification required

## Decentralization Bonus
Pools with <5% network hashrate receive +2% fee bonus
Pools with >20% network hashrate are penalized -1% fee

## Community Campaigns
- Share mining dashboard screenshots
- Write mining tutorials
- Refer new miners (5% of their pool fees for 30 days)
