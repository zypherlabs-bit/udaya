# Udaya Ecosystem Grant Framework

## Overview
The Udaya Ecosystem Grant Program provides funding to developers, researchers, and community members building on or for the Udaya network.

## Grant Tiers
| Tier | Max Funding | Focus Area |
|------|-------------|------------|
| **Micro** | 1,000 UDYA | Documentation, tutorials, small tools |
| **Standard** | 10,000 UDYA | SDKs, wallets, libraries, integrations |
| **Major** | 50,000 UDYA | Protocol development, Layer-2, infrastructure |
| **Strategic** | 100,000+ UDYA | Foundation-level initiatives, core protocol |

## Priority Areas
1. Wallet and UX improvements
2. Developer tools and SDKs
3. Mining decentralization
4. Exchange integration tooling
5. Security research and audits
6. Educational content and documentation
7. Community infrastructure (explorers, dashboards)
8. Layer-2 scaling solutions

## Application Requirements
- Project roadmap with milestones
- Team background and credentials
- Open-source commitment
- Regular progress reports

## Payment Schedule
- 25% on approval
- 25% on first milestone
- 25% on second milestone
- 25% on completion

## Reporting
- Monthly progress updates
- Final deliverable and documentation
- Financial accountability report
