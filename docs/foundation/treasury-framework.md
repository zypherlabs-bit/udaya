# Udaya Treasury Governance Framework

## 1. Treasury Overview
The Udaya Treasury is a transparent, multi-signature controlled fund that supports the ecosystem's growth and sustainability.

**Address**: UDYA1qtreasury000000000000000000000000000000
**Balance**: 145,678 UDYA (as of May 2026)
**Custodians**: 7 Foundation Council members (5-of-7 multisig)

## 2. Fund Sources
| Source | Allocation | Schedule |
|--------|-----------|----------|
| Block Subsidy | 1 UDYA/block (2% of 50 UDYA) | Every block forever |
| Donations | 100% | Voluntary |
| Partnership Fees | Per agreement | Variable |

## 4. Grant Application Process
1. Submit BFIP with detailed budget
2. 14-day community feedback period
3. Treasury Committee due diligence
4. Council vote (majority for <10K, supermajority for 10K-100K)
5. On-chain vote for >100K UDYA
6. Multi-sig release on milestone completion

## 5. Reporting
- Monthly: Income statement, balance sheet, transaction log
- Quarterly: Ecosystem impact report
- Annual: Independent audit
