## Bug Reporting

### 🐛 How to Report Bugs

1. **Search First**: Check if the issue has already been reported
2. **Use the Template**: Follow the bug report template in GitHub Issues
3. **Provide Details**:
   - Environment (OS, Rust version, architecture)
   - Steps to reproduce
   - Expected vs actual behavior
   - Logs and error messages
4. **Label Correctly**: Use "Phase3-Testing" label
5. **Be Responsive**: Answer follow-up questions from maintainers

### 🏷️ Bug Severity Guidelines

| Severity | Criteria | Examples |
|----------|----------|----------|
| **Critical** | Causes data loss, security vulnerabilities, or complete system failure | Consensus bugs, fund loss, RCE vulnerabilities |
| **High** | Major functionality broken, severe performance degradation | Node crashes, failed transactions, API timeouts |
| **Medium** | Minor functionality issues, usability problems | Edge cases, error handling, documentation gaps |
| **Low** | Cosmetic issues, minor inconveniences | Typos, formatting, non-critical warnings |

## FAQ

### ❓ Common Questions

**Q: How much time do I need to commit?**
A: Any contribution is valuable! Even 1-2 hours per week helps. The more time you can dedicate, the deeper you can test.

**Q: Do I need to be a Rust expert?**
A: Not at all! We need testers with diverse backgrounds - sysadmins, developers, security researchers, technical writers, etc.

**Q: What if I break something?**
A: That's the whole point! This is alpha software in a test environment. You can't break anything important.

**Q: How do I get help if I'm stuck?**
A: Ask in this discussion thread or our Discord server. The community and maintainers are here to help!

**Q: Are there any rewards?**
A: Yes! We have a bug bounty program and will recognize top contributors. See the [Alpha Announcement](https://github.com/UdayaFoundation/Udaya/blob/main/docs/operations/alpha-announcement.md) for details.

## Getting Help

### 🆘 Support Channels

1. **Ask here**: Post your question in this discussion
2. **Discord**: Get real-time help in our #testing channel
3. **GitHub Issues**: For bug reports and feature requests
4. **Documentation**: Check our comprehensive guides first

### 🔍 Before Asking

1. Search existing discussions and issues
2. Check the documentation
3. Try to reproduce the issue
4. Prepare relevant details (logs, config, environment)

### ✅ Good Question Example

> **Subject**: Transaction broadcasting issue on Windows
>
> **Body**:
> Hi team! I'm experiencing an issue with transaction broadcasting on Windows 11. Here's what I've tried:
>
> 1. Built from source using `cargo build --release`
> 2. Started node with `./target/release/udayad --config config/udaya.conf`
> 3. Tried to send a transaction using `udaya-cli sendtoaddress <address> <amount>`
>
> The transaction appears to hang and never confirms. I've attached:
> - My configuration file (sanitized)
> - Relevant debug logs
> - System information
>
> Has anyone else experienced this? Any suggestions for troubleshooting?
