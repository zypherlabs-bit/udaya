# 🌟 First-Time Contributor Guide

Welcome to Udaya! We're excited you're interested in contributing. This guide will help you get started.

## 🚀 Getting Started

### 1. Set Up Your Environment

```bash
# Install prerequisites
git clone https://github.com/contactzypherlabs-cell/udaya.git
cd udaya
rustup install stable
cargo build
```

### 2. Find an Issue

- Look for issues labeled **"good first issue"**
- Check the **"help wanted"** label for contributions
- Browse open issues and find something interesting

### 3. Claim the Issue

- Comment on the issue to let us know you're working on it
- Wait for confirmation before starting work

### 4. Create a Branch

```bash
git checkout -b feature/your-feature-name
```

### 5. Make Your Changes

- Follow our [Coding Standards](#coding-standards)
- Write tests for your changes
- Update documentation if needed

### 6. Submit a Pull Request

```bash
git add .
git commit -m "Fix: brief description of changes"
git push origin feature/your-feature-name
```

Then create a PR on GitHub following our [Pull Request Template](.github/pull_request_template.md)

## 📖 Coding Standards

### Rust Standards
- Follow [Rust API Guidelines](https://rust-api-guidelines.github.io/)
- Use `clippy` for linting: `cargo clippy --all-targets`
- Format code: `cargo fmt`

### Commit Messages
- Use present tense ("Add feature" not "Added feature")
- Limit first line to 72 characters
- Reference issues when applicable

### Documentation
- Update docstrings for public APIs
- Add examples where helpful
- Keep READMEs up to date

# 🛡️ Udaya Security Testing Guide

This guide provides instructions for security testing the Udaya alpha release.

## 🔒 Security Testing Scope

### In Scope
- **Network Protocol Security**: P2P and RPC communications
- **Wallet Security**: Key management and transaction signing
- **Consensus Security**: Block validation and chain rules
- **API Security**: Authentication and authorization
- **Dependency Security**: Supply chain vulnerabilities

### Out of Scope (for Alpha)
- **Smart Contract Security**: Not yet implemented
- **Lightning Network Security**: Experimental implementation
- **Mobile Wallet Security**: Native apps in development

## 🔍 Testing Methodologies

### 1. Network Security Testing

**Tools**: Wireshark, tcpdump, custom packet crafting

**Tests:**
- **Eavesdropping**: Verify encryption of P2P traffic
- **MITM Attacks**: Test resistance to man-in-the-middle
- **DoS Resistance**: Test flood protection
- **Sybil Attacks**: Test peer validation

### 2. Wallet Security Testing

**Tests:**
- **Mnemonic Validation**: Test BIP39 compliance
- **Key Derivation**: Verify BIP32/44/49/84 paths
- **Transaction Signing**: Test ECDSA signature validation
- **Address Generation**: Verify bech32 encoding

### 3. API Security Testing

**Tests:**
- **Authentication Bypass**: Test RPC authentication
- **Input Validation**: Test for injection vulnerabilities
- **Rate Limiting**: Test DoS protection
- **TLS Configuration**: Verify cipher suites

### 4. Dependency Analysis

**Tools**: `cargo-deny`, `cargo-audit`

**Tests:**
- **Vulnerability Scanning**: Check for known CVEs
- **License Compliance**: Verify license compatibility
- **Supply Chain**: Check dependency sources

## 🚨 Responsible Disclosure

**DO NOT** report security vulnerabilities publicly!

Follow our [SECURITY.md](SECURITY.md) process:
1. Email: security@udayafoundation.org
2. PGP Key: [Available in SECURITY.md]
3. Response Time: 24-48 hours for critical issues
