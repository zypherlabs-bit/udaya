## Usage

- **Logo files** (`udaya-logo.png`, `udaya-logo-transparent.png`): 1024x1024
  high-resolution masters for professional use, documentation, and social
  media Open Graph images.
- **Icon** (`udaya-icon.png`): 128x128 for application icons, Apple touch icons,
  and in-page navigation branding.
- **Web sizes** (`udaya-logo-512.png`, `udaya-logo-256.png`): Optimized
  intermediate sizes for web applications.
- **Favicon** (`favicon.png`): 32x32 for browser tab icons.
