📖 Mining Tutorials

Step-by-step guides for all mining setups.

Beginner

🖥️ Solo CPU Mining

Start mining UDYA with your computer's CPU. Perfect for testing and small-scale mining.

  1. Build: cargo build --release
  2. Create wallet: ./target/release/udaya-wallet create
  3. Start mining: ./target/release/udayad start --mine
Intermediate

🏊 Pool Mining Setup

Join a mining pool for consistent payouts via Stratum V2 protocol.

  1. Get wallet address
  2. Connect: pool.Udaya.net:3333
  3. Mine: ./target/release/udaya-miner --pool stratum+tcp://pool.Udaya.net:3333 --wallet ADDR
Advanced

⚡ ASIC Mining

Configure BF-ASIC or third-party SHA-256 ASIC miners for maximum performance.

  1. Configure ASIC to point at any UDYA pool
  2. Use Stratum V2 for best efficiency
  3. Monitor via pool dashboard
  4. Optimize power/frequency for efficiency
