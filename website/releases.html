Udaya Global — independent Layer-1 blockchain (U-ADC consensus).

Release status: NO-GO for production mainnet. The codebase passes all achievable automated quality, correctness, consensus and monetary-isolation gates, but production launch conditions are not yet met (no wallet, no external security audit, no transport hardening, no separately authorized reward reserve, no signed release). See the GO/NO-GO report. Do not treat any artifact below as production-ready mainnet software.

Node installation

Build from source

Udaya Global is a Rust workspace (edition 2021). Build and test with:

cargo build --workspace
cargo test --workspace
cargo clippy --workspace --all-targets
cargo fmt --check --all

The GNU Windows target requires the MinGW linker from C:\msys64\mingw64\bin (set CARGO_TARGET_X86_64_PC_WINDOWS_GNU_LINKER).
